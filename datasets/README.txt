This is the foundation dataset for - Enterprise Warehouse Performance Investigation Copilot.

Folder structure:
- warehouse_kpi_data.csv: populated warehouse KPI fact table
- employee_hierarchy.csv: employee/team leader/manager hierarchy
- warehouse_master.csv: 12 warehouse master data
- warehouse_benchmarks.csv: KPI benchmark thresholds
- recommendation_rules.csv: recommendation rules for action planning
- demo_questions.csv: suggested demo questions
- data_dictionary.csv: column dictionary
